\# BurgerPortaal Mendix API



Python proof-of-concept scripts for retrieving Dutch waste collection schedules from the BurgerPortaal Mendix API.



\## Scripts



\- `burgerportaal\_test\_v3.py` — Earlier API investigation and testing.

\- `burgerportaal\_test\_v5.py` — Extended implementation for retrieving waste collection dates.



\## Status



\- Tested with the Breda municipality.

\- Uses Mendix sessions, cookies and CSRF tokens.

\- Supports postcode and numeric house number input.

\- Other municipalities and house number additions have not yet been tested.
